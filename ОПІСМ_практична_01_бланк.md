<h1 class="sd-d-none">Mercurial SCM<a class="headerlink" href="#mercurial-scm" title="Link to this heading">#</a></h1>
<div class="sd-container-fluid sd-sphinx-override sd-mt-1 sd-mb-2 sd-ml-1 sd-mr-2 docutils">
<div class="sd-row sd-g-3 sd-g-xs-3 sd-g-sm-4 sd-g-md-4 sd-g-lg-4 sd-flex-row-reverse docutils">
<div class="sd-col sd-d-flex-column sd-col-12 sd-col-xs-12 sd-col-sm-4 sd-col-md-4 sd-col-lg-4 docutils">
<a class="sd-m-auto reference internal image-reference" href="_images/logo-hg.svg"><img alt="_images/logo-hg.svg" class="sd-m-auto" src="_images/logo-hg.svg" style="width: 150px;" />

</div>
<div class="sd-col sd-d-flex-column sd-col-12 sd-col-xs-12 sd-col-sm-8 sd-col-md-8 sd-col-lg-8 sd-align-major-justify sd-fs-5 docutils">
<p class="rubric">Work easier, Work faster</p>
<p>Mercurial is a free, distributed source control management tool. It efficiently handles
projects of any size and offers an easy and intuitive interface.</p>
</div>
<div class="sd-col sd-d-flex-column docutils">
<p class="rubric" id="quick-start">Quick Start</p>
<p><em>Clone a project and push changes</em></p>
<div class="highlight-sh notranslate"><div class="highlight"><pre><span></span>hg<span class="w"> </span>clone<span class="w"> </span>https://www.mercurial-scm.org/repo/hello
<span class="nb">cd</span><span class="w"> </span>hello
<span class="c1"># (edit files)</span>
hg<span class="w"> </span>add<span class="w"> </span><span class="o">(</span>new<span class="w"> </span>files<span class="o">)</span>
hg<span class="w"> </span>commit<span class="w"> </span>-m<span class="w"> </span><span class="s1">&#39;My changes&#39;</span>
hg<span class="w"> </span>push
</pre></div>
</div>
<p><em>Create a project and commit</em></p>
<div class="highlight-sh notranslate"><div class="highlight"><pre><span></span>hg<span class="w"> </span>init<span class="w"> </span><span class="o">(</span>project-directory<span class="o">)</span>
<span class="nb">cd</span><span class="w"> </span><span class="o">(</span>project-directory<span class="o">)</span>
<span class="c1"># (add some files)</span>
hg<span class="w"> </span>add
hg<span class="w"> </span>commit<span class="w"> </span>-m<span class="w"> </span><span class="s1">&#39;Initial commit&#39;</span>
</pre></div>
</div>
</div>
</div>
</div>
<hr class="docutils" />
<p class="rubric">How you can benefit from Mercurial</p>
<div class="sd-container-fluid sd-sphinx-override sd-mb-4 docutils">
<div class="sd-row sd-row-cols-1 sd-row-cols-xs-1 sd-row-cols-sm-2 sd-row-cols-md-2 sd-row-cols-lg-3 sd-g-1 sd-g-xs-1 sd-g-sm-1 sd-g-md-1 sd-g-lg-2 docutils">
<div class="sd-col sd-d-flex-row docutils">
<div class="sd-card sd-sphinx-override sd-w-100 sd-shadow-sm docutils">
<div class="sd-card-body docutils">
<div class="sd-card-title sd-font-weight-bold docutils">
It is <a class="reference internal" href="about.html"><span class="std std-doc">fast and powerful</span></a></div>
<p class="sd-card-text">Mercurial efficiently handles <a class="reference internal" href="who.html"><span class="std std-doc">projects of any size and kind</span></a>. Every clone
contains the whole project history, so most actions are local, fast and convenient.

## Контрольні питання

**1. Скільки рядків діагностичного виводу передує отриманню даних сторінки (завдання A.1)?**

> 48 рядків діагностичного виводу передують отриманню даних сторінки

**2. Які рядки наявні у виводі A.1 і відсутні у виводі A.2? Чим це зумовлено?**

> У виводі A.1 наявні такі рядки: `SSL connection using TLSv1.3`,`(304) (IN), TLS handshake, Server hello (2):`,` SSL certificate verify ok.`
> Цих рядків немає у виводі A.2, бо у А.2 використовується http, тоді як у A.1 використовується https

**3. Звідки у виводі з'явилося значення `443`, якщо його не було вказано в адресі?**

> 443 є портом за замовчуванням для протоколу HTTPS

**4. Як змінилося значення TTL між двома запитами (A.3)? Що означає це число?**

> В моєму випадку значення TTL збільшилось з 284 до 300. Це число означає скільки за часом IP-адреса ще буде зберігатися в DNS-пам'яті

**5. Чим відрізняються між собою три причини помилок із завдання A.5? Сформулювати кожну однією фразою.**

| Випадок | Причина недовіри |
|---|---|
| `expired` | Вичерпано термін дії сертифіката |
| `wrong.host` | Домен є недостовірним |
| `self-signed` | Сертифікат є самопідписаним |

**6. Три рядки з власних виводів, про які не йшлося на лекції 1:**

| № | Рядок виводу | Джерело (номер завдання) |
|---|---|---|
